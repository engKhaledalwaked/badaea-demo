# بدائع لبنان للديكور — Wonderful Lebanon for Decoration (Demo)

نسخة عرض (واجهة أمامية) لموقع **بدائع لبنان للديكور** (فرع العليا العام، الرياض) — تجهيز المراكز والمعارض التجارية والفنادق. Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: GitHub ثم Import (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
من صفحة المحل على خرائط Google (87 صورة، اخترت أفضلها): الواجهة ليلاً ونهاراً، المعرض، وصور المنتجات الفعلية (علاقات، مانيكانات، شماعات، أرفف، ترولي، سلال ذهبية، مرايا، أعلام، طاولات مقاهي، ستاندات مجوهرات).
الهوية: الأخضر الليموني من اللافتة النهارية + الأسود من اللافتة الليلية + الذهبي من المنتجات.
موقعهم الحالي badaalebanon.com دومينه غير موجود. لم أجد حساب سوشيال ظاهراً.

## ميزة خاصة
**قائمة عرض السعر**: الزائر يضيف المنتجات (مع الكمية) ويرسل القائمة كاملة على واتساب — مناسبة لعملاء المشاريع (محلات، فنادق، مقاهي).
فلترة المنتجات حسب نوع المشروع.

## تنبيهات
- رقم الواتساب 055 994 1663 مكتوب على لافتة المحل نفسها.
- "فرع الخزان" ظاهر في خرائط Google باسم "بدائع لبنان (الخزان)" — تأكد أنه نفس الشركة.
- أوصاف المنتجات عامة مبنية على الصور، بدون أسعار.
